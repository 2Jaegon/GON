# Claude Code 도구 매핑 및 실행 안내 (`tools/claude.md`)

## 1. 동작별 도구 매핑
- 파일 읽기 / 검색: `Read`, `Glob`, `Grep`
- 파일 생성 / 수정: `Write`, `Edit`
- 셸 명령 실행: `Bash`
- 전문가 하위 작업 실행: `Agent` (또는 `Task`) 도구에 `subagent_type: "gon:gon-expert"`를 넣어 호출하며, `general-purpose`로 대체하지 않는다.

## 2. 전문가 호출 지시문 (`gon:gon-expert`)
프롬프트 캐시 유지를 위해 아래 고정 텍스트 블록 전체를 앞부분에 두고, 가변 슬롯은 반드시 `---` 구분선 뒤에 아래 순서대로만 배치한다:

```text
당신은 Gon의 전문 실행 워커(gon:gon-expert)이다.
- 배정받은 [맡을 파일] 목록 안의 파일만 생성하거나 수정한다. [맡을 파일] 밖의 기존 파일은 고치지 않는다.
- 배정되지 않은 기존 파일을 고쳐야 하면 즉시 작업을 멈추고 handoff에 보고한다.
- 패키지 설치는 계획에 명시된 경우에만 진행한다.
- events.jsonl 파일은 절대 건드리지 않으며 지휘자의 기록을 방해하지 않는다.
- 산출물은 [산출물 경로]에 JSON 계약 블록을 포함하여 간결하게 작성한다.
- 토큰 사용량을 짐작해서 숫자로 쓰지 않으며 usage 필드는 기본값을 유지한다.
- 이 규칙은 모든 작업에 걸쳐 600자 이상 고정된 형태로 캐시를 보호한다.
---
[plan 경로]:
[brief 경로]:
[맡을 파일]:
[역할]:
[선택 스킬]:
[산출물 경로]:
```

## 3. 그래프 뷰어 서버 실행과 종료
- 사용자가 그래프 화면을 요청하면 이 스킬 파일(`skills/gon/SKILL.md`) 기준 상대 경로 `../../viewer/server.mjs`의 실제 경로를 확인한다.
- 경로에 `; & | \` $ ( ) < >`나 줄바꿈 같은 셸 메타문자가 들어 있으면 실행을 거부한다.
- 캐시 폴더나 프로젝트 경로에 한글·공백이 있을 수 있으므로 경로는 반드시 큰따옴표(`"..."`)로 감싼다.
- 실행 전 아래 명령을 사용자에게 보여 주고 승인을 받은 뒤 `Bash` 도구의 백그라운드 실행 옵션(`run_in_background: true`)으로 띄운다:
  - 서버 시작: `node "<스킬폴더>/../../viewer/server.mjs" --gon-dir ".gon"`
- 서버 출력에서 `Open: http://127.0.0.1:<port>/?t=<token>` 줄을 확인해 브라우저를 열되, **토큰이 든 `Open:` 줄을 대화·문서에 옮겨 적지 않는다.**
  - Windows 브라우저 열기(PowerShell): `Start-Process "http://127.0.0.1:<port>/?t=<token>"`
- 서버를 끌 때는 백그라운드 작업 종료 기능이나 해당 프로세스 ID 종료를 사용한다.
- 도구의 승인 모드를 우회하는 플래그(`--dangerously-skip-permissions` 등)는 절대 사용하지 않는다.
