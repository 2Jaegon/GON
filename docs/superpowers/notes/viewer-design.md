# Gon 읽기 전용 그래프 뷰어 설계 (`viewer-design.md`)

## 1. 목적·독자·첫 시선·기본 행동
- **화면의 일(Purpose)**: 사용자의 AI 채팅에서 `/gon`으로 진행 중인 7단계 작업 흐름과 전문가 분업 상태를 실시간 점·선 그래프로 보여 주고, 각 점이 만든 요약과 산출물(`.md`)을 안전하게 읽게 한다.
- **읽는 사람(Audience)**: 프롬프트·터미널·코드 구조에 익숙하지 않은 비전문가.
- **첫 시선(Visual Hierarchy)**:
  1. 상단 상태 바: 현재 진행 상태 배지(진행 중 / 완료 / 멈춤? / 권한 없음)와 요청 목록 요약
  2. 왼쪽·중앙 캔버스: 메인 점에서 오른쪽으로 뻗어 나가는 단계별 점·선 그래프(진행 중인 가지는 선명하게, 끝난 가지는 흐리게 차선별로 적층)
  3. 오른쪽 상세 패널: 선택한 점의 한 일(`sum`), 단계·역할, 상태, 소요 시간, `fallback`·`inline` 여부, 바꾼 파일 목록(`files`), 산출물 마크다운(`out`)
- **기본 행동(Primary Action)**: 그래프의 점을 마우스 클릭하거나 `Tab` → `Enter`/`Space`로 선택해 오른쪽 패널에서 해당 단계가 한 일을 읽는다.
- **목표 뷰포트(Target Viewports)**:
  - 데스크톱 `1440x900`: 좌측 그래프 캔버스(가변 폭) + 우측 고정 폭(`400px`) 상세 패널 2단 배치
  - 모바일 `390x844`: 상단 그래프 캔버스 + 하단 상세 패널 수직 배치(가로 스크롤은 SVG 래퍼 내부에만 한정해 페이지 가로 넘침 0)

## 2. 색·글꼴·간격 토큰 (보라 그라디언트 금지)
CSP(`style-src 'self'`)와 오프라인 동작을 위해 외부 웹폰트를 쓰지 않고 OS 내장 한글·고정폭 글꼴을 쓴다.

- **배경/표면**: `--bg-canvas: #F8FAFC`, `--bg-panel: #FFFFFF`, `--bg-muted: #F1F5F9`, `--border: #CBD5E1`
- **글자(대비 4.5:1 이상)**: `--ink: #0F172A` (15.8:1), `--ink-secondary: #334155` (9.3:1), `--ink-muted: #475569` (7.0:1)
- **상태 의미 색**:
  - `main`(시작점): `#0F172A`
  - `running`(진행 중): `#0D9488` (틸, 배경 `#CCFBF1`, 텍스트 `#115E59`)
  - `done`(완료): `#15803D` (그린, 배경 `#DCFCE7`, 텍스트 `#166534`)
  - `failed`(실패): `#B91C1C` (레드, 배경 `#FEE2E2`, 텍스트 `#991B1B`)
  - `stalled`(멈춤?): `#C2410C` (앰버/오렌지, 배경 `#FFEDD5`, 텍스트 `#9A3412`)
  - `skipped`(건너뜀): `#64748B` (슬레이트, 배경 `#E2E8F0`, 텍스트 `#334155`)
  - 포커스 링: `--focus-ring: #0284C7` (`3px solid`)
- **글꼴**:
  - 본문: `'Pretendard', 'Malgun Gothic', -apple-system, BlinkMacSystemFont, system-ui, sans-serif`
  - 코드/ID: `'Cascadia Mono', 'Consolas', ui-monospace, monospace`

## 3. 상태 6종 계약 (Evidence & Content States)

| 상태 (State) | 트리거 (Trigger) | 시각적 피드백 (Visible Feedback) | 안전한 다음 행동 (Safe Next Action) |
|---|---|---|---|
| **Loading** | 초기 `/api/runs` 및 상세 데이터 요청 중 | 상단 상태 배지에 "불러오는 중…" 표시, 레이아웃 골격 유지 | 응답 완료 시 자동으로 그래프 렌더 |
| **Empty** | `.gon/` 폴더가 없거나 완료/진행 기록이 0건일 때 | 빈 상태 안내("아직 기록된 Gon 작업이 없습니다") 표시 | AI 채팅창에서 `/gon <아이디어>`를 입력하라고 안내 |
| **Error** | 서버 연결 실패 또는 `/api/*` 네트워크/5xx 오류 | 상단 오류 배너에 구체적 원인과 "다시 시도" 버튼 표시 | "다시 시도" 버튼 클릭 또는 서버 재실행 안내 |
| **Partial** | `events.jsonl`에 깨진 줄(`skipped > 0`)이 있거나 `stalled`(10분 이상 멈춤), 또는 `out` 파일을 열 수 없을 때 | 온전한 점들은 정상 표시하고 상단에 "일부 기록 줄 건너뜀(N줄)" 또는 "멈춤?" 배지 표시, 잘못된 `out` 경로는 "열 수 없음" 표시 | 확인 가능한 점의 산출물을 열람하거나 AI 채팅에서 진행 상태 점검 |
| **Success** | 모든 기록과 선택한 점의 `.md` 산출물이 정상 로드됨 | 단계별 점·선 그래프와 우측 패널에 요약·소요 시간·파일 목록·정제된 마크다운 표시 | 다른 점을 클릭/키보드로 탐색 |
| **Permission** | `?t=` 토큰이 없거나 만료·불일치하여 `/api/*`가 `403`을 반환할 때 | 데이터 노출 없이 권한 안내 화면("접근 토큰이 없거나 만료되었습니다") 표시 | 터미널에 출력된 `Open: http://127.0.0.1:<port>/?t=<token>` 주소로 다시 열기 |

## 4. 접근성 및 보안 규칙
- 모든 그래프 점(`<g role="button" tabindex="0">`)은 키보드 `Tab` 이동과 `Enter`/`Space` 선택을 지원하며 `:focus-visible` 외곽선을 표시한다.
- 상태는 색상뿐 아니라 한글 상태 라벨(`진행 중`, `완료`, `실패`, `멈춤?`)로 함께 표시한다.
- `@media (prefers-reduced-motion: reduce)`에서 진행 중 점의 깜빡임/애니메이션을 끈다.
- `index.html`, `app.js`, `style.css`, SVG 어디에도 인라인 스크립트, `style=` 속성, `on*=` 이벤트 속성을 쓰지 않으며, `innerHTML`은 `renderMarkdown()`이 반환한 정제된 HTML을 넣을 때만 사용한다.
