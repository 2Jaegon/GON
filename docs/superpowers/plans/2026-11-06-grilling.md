# Grilling (Adaptive Clarification & Requirement Refining) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or executing-plans to implement this plan task-by-task.

**Goal:** 구현·조사 요청에서 요구사항이 모호한 경우 에이전트가 `[Grilling]` 마커와 함께 추천 답안을 포함한 3~4개의 명확화 질문을 제시하고, 서버가 이를 감지하여 UI에 Grilling 상태 배지를 표시하며, 사용자가 "질문 없이 바로" 옵션으로 건너뛸 수 있도록 지원한다.

---

### Task 1: P3-1 Grilling 시스템 프롬프트 지침 (`packages/provider-adapters`)
- 파일:
  - Modify: `packages/provider-adapters/src/agent-prompt.ts`
  - Modify: `tests/aso-web/agent-prompt.test.ts`
- 요구사항:
  - `AgentPromptOptions`에 `grilling?: boolean` 추가 (기본값: false 또는 명시적 제어).
  - grilling이 활성화되면 명확화 지침(짧은 요청, 대상 부재, 완료 기준 부재, 위임 표현 판별, 첫 줄 `[Grilling]` 마커, 도구 호출 대신 텍스트 질문) 주입.
  - grilling이 비활성화(skipGrilling)되면 해당 지침 제외.

### Task 2: P3-2 서버 Grilling 감지 및 이벤트 발행 (`apps/api/src/services/agent-service.ts`)
- 파일:
  - Modify: `apps/api/src/services/agent-service.ts`
  - Modify: `tests/aso-web/agent-service.test.ts`
- 요구사항:
  - 스트리밍 텍스트 또는 도구 사용(`Skill` with `/grill/i`)에서 Grilling 감지.
  - 감지 시 `agent:grilling` (`{ state: "asking" }`) 이벤트 발행.
  - 클라이언트로 전달되는 `chat:delta` 및 최종 텍스트에서 `[Grilling]` 접두 줄 제거.
  - 세션 재개(이전 세션이 asking 상태) 시 `agent:grilling` (`{ state: "answered" }`) 발행.

### Task 3: P3-3 UI 배지 및 스타일 (`apps/web/public/agent-ui.js`, `style.css`, `app.js`)
- 파일:
  - Modify: `apps/web/public/agent-ui.js`
  - Modify: `apps/web/public/style.css`
  - Modify: `apps/web/public/app.js`
  - Test: `tests/aso-web/agent-ui.test.ts`
- 요구사항:
  - `grillingBadgeHtml(state: "asking" | "answered"): string` 순수 함수 제공.
  - SSE `agent:grilling` 수신 시 해당 런 메시지 상단에 배지 렌더링.

### Task 4: P3-4 Grilling 건너뛰기 (`skipGrilling` DTO & API 연동)
- 파일:
  - Modify: `packages/contracts/src/runs.ts`
  - Modify: `apps/api/src/routes/runs.ts`
  - Modify: `apps/api/src/services/agent-service.ts`
  - Modify: `apps/web/public/index.html`
  - Modify: `apps/web/public/app.js`
  - Test: `tests/aso-web/grilling-skip.test.ts`
- 요구사항:
  - `CreateRunDTO`에 `skipGrilling?: boolean` 필드 추가.
  - Run 생성 시 `runContext.skipGrilling` 저장 및 `AgentService` 시작 시 `grilling: !run.runContext?.skipGrilling` 전달.
  - Web UI 입력 영역에 "질문 없이 바로" 체크박스/토글 제공.
