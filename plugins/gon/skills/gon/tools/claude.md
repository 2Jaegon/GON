# Claude Code 도구 매핑 및 서버 실행 안내 (`tools/claude.md`)

## 1. 동작별 도구 매핑
- 파일 읽기 / 검색: `Read`, `Glob`, `Grep`
- 파일 생성 / 수정: `Write`, `Edit`
- 셸 명령 실행: `Bash`
- 전문가 하위 작업 병렬 실행: `Agent` (또는 `Task`) 도구에 `subagent_type: "gon:gon-expert"`를 넣어 한 메시지에서 여러 개 동시에 호출한다.

## 2. 전문가 병렬 호출 지시문 (`gon:gon-expert`)
- 여러 전문가를 실행할 때는 한 응답 안에서 `Agent` 도구 호출을 동시에 여러 개 발송해 병렬로 돌린다.
- 프롬프트 캐시가 유지되도록 모든 전문가에게 동일한 고정 안내문을 앞부분에 두고, 바뀌는 값은 맨 끝에 아래 순서로만 적는다:
  1. `[카드 경로]`: `.gon/<run_id>/compose.md` 또는 해당 단계 카드 경로
  2. `[brief 경로]`: `.gon/<run_id>/brief.md`
  3. `[맡을 파일]`: 이 전문가에게 배정된 프로젝트 상대 경로 목록
  4. `[역할]`: 전문가 역할 이름 (예: `frontend`, `backend`, `qa`)
  5. `[산출물 경로]`: `.gon/<run_id>/<id>.md`

## 3. 그래프 뷰어 서버 실행과 종료
- 사용자가 그래프 화면을 요청하면 이 스킬 파일(`skills/gon/SKILL.md`)이 있는 폴더 기준 상대 경로 `../../viewer/server.mjs`의 실제 경로를 확인한다.
- 경로에 `; & | \` $ ( ) < >`나 줄바꿈 같은 셸 메타문자가 들어 있으면 실행을 거부한다.
- 캐시 폴더나 프로젝트 경로에 한글·공백이 있을 수 있으므로 경로는 반드시 큰따옴표(`"..."`)로 감싼다.
- 실행 전 아래 명령을 사용자에게 보여 주고 승인을 받은 뒤 `Bash` 도구의 백그라운드 실행 옵션(`run_in_background: true`)으로 띄운다:
  - 서버 시작: `node "<스킬폴더>/../../viewer/server.mjs" --gon-dir ".gon"`
- 서버 출력에서 `Open: http://127.0.0.1:<port>/?t=<token>` 줄을 확인해 브라우저를 열되, **토큰이 든 `Open:` 줄을 대화·문서에 옮겨 적지 않는다.**
  - Windows 브라우저 열기(cmd/bash): `start "" "http://127.0.0.1:<port>/?t=<token>"`
  - Windows 브라우저 열기(PowerShell): `Start-Process "http://127.0.0.1:<port>/?t=<token>"`
- 서버를 끌 때는 백그라운드 작업 종료 기능이나 해당 프로세스 ID 종료를 사용한다.
- 도구의 승인 모드를 우회하는 플래그는 절대 안내하거나 사용하지 않는다. 플러그인 설치·갱신 뒤에는 `/reload-plugins` 또는 세션 재시작을 안내한다.
