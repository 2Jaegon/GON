# Gon

Gon은 프롬프트나 복잡한 설정을 몰라도 한 줄 아이디어만 말하면 **질문(그릴링) → 기획 → 점검 및 승인 → 작업 구성 → 전문가 병렬 실행 → 결과 종합 및 검증**의 7단계로 실제 코드를 만들어 주는 Claude Code용 스킬팩입니다.

작업 진행 과정은 프로젝트 안 `.gon/` 폴더에 기록되며, 필요할 때 읽기 전용 로컬 그래프 화면을 열어 각 단계와 전문가가 한 일을 점과 선으로 실시간 확인할 수 있습니다.

## 1. 설치 (터미널에서 두 줄 입력)

```bash
claude plugin marketplace add 2Jaegon/Gon
claude plugin install gon@gon
```

설치 후 Claude Code 채팅창에서 `/reload-plugins`를 입력하거나 세션을 재시작하면 바로 사용할 수 있습니다.
(보조 수단으로 AI에게 `"GON 설치해줘"`라고 말하면, AI가 `INSTALL.md`의 고정 명령을 보여 주고 승인을 받아 대신 실행합니다.)

## 2. 첫 실행과 사용법

원하는 프로젝트 폴더에서 Claude Code를 열고 아래와 같이 호출하세요:

```text
/gon 할 일 목록 CLI 만들어줘
```

또는 `"gon으로 할 일 목록 CLI 만들어줘"`라고 말해도 됩니다.
- 첫 실행 시 권장 스킬 확인, `.gon/` 기록 폴더 생성 동의, `.gitignore` 추가 여부, 그래프 화면 사용 여부를 차례로 안내합니다.
- 깊이 조절이 필요하면 `"빠름으로"`, `"보통으로"`, `"깊게로"`라고 덧붙일 수 있습니다(기본값은 보통).
- 실행 중 `"그래프 보여줘"`라고 말하면 로컬 읽기 전용 그래프 화면 주소를 안내받을 수 있습니다.

## 3. 삭제

```bash
claude plugin uninstall gon@gon
```

Gon은 사용자의 전역 설정 파일을 건드리지 않으므로 위 명령 한 줄로 깔끔하게 제거됩니다.
